
# hello_world

Welcome to the **hello_world** project! This project demonstrates a beautiful web tribute to the rise of SUI, the next-generation blockchain platform.

This project is a simple demonstration of Move and web integration.
It features a glowing tribute to the SUI blockchain on a modern web page.
Explore how Move modules and web technologies can work together beautifully.


## ✦ SUI Tribute ✦
Experience a glowing, animated section on the web page that celebrates SUI's innovation, scalability, and the vision of Mysten Labs. The tribute highlights SUI's object-centric model and parallel execution, setting a new standard for blockchain technology.

Open `web/index.html` in your browser to see the tribute in action!

## Navigation
The main page now includes a link to a Welcome page. Click "Welcome →" to visit the welcome screen, which now features a login form (username and password), a "Don't have an account? Sign Up" link next to Login, and a link back to the home page.
